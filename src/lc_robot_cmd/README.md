## 1.设计目标

哨兵读取裁判系统消息，最好能实现以下行为：

- 1.读取裁判系统比赛开始指令，自动出家占领得分点（从一个点导航到另一个点）
- 2.当血量低于阈值，自动导航回家
- 3.自瞄锁定敌人的时候，导航能取消旋转锁敌的状态，改而使机器人面朝敌人，自动设置离敌人一定距离的导航点，保持距离追击

## 2.框架设计思路

采用FSM状态机，设置机器人状态表，根据外部传感器消息切换机器人状态，调用nav2接口进行导航，追击等行为。

## 3.开发流程和时限

**1.首先封装好对nav2的Action接口的调用和状态机的切换，分别在仿真和实车上测试**

[测试目标]能实现两点间的来回自动导航，例如从A点自动导航到B点，在B点停留一定时间后自动再导航回A点循环往复。

**2.自动瞄准联动。哨兵是两台电脑，预计将导航机的消息发送到自瞄机上，由自瞄机整合数据发送到串口。需要在自瞄的观测节点将识别到的目标运动状态发送给导航机，由lc_robot_cmd接收。**

[测试目标]能实现在哨兵巡回状态时切换到追击状态，追击完成后自动切换到巡回状态或者回家（完整形态要求）
